# Simba Cement Website

Static marketing website for Simba Cement Company, built with HTML and Tailwind CSS.

## Development

Install dependencies and build the production stylesheet:

```bash
npm install
npm run build
```

To serve the site locally, use any static file server with `public/` as its document root. For example:

```bash
npx serve public
```

The main page is `public/index.html`; the products page is `public/products.html`.

## Deployment

The deployable site is the `public/` directory. It can be hosted on GitHub Pages, Netlify, Vercel, or any static web host.
